# LYREBIRD

Short-form video breakdown and brief tool | Software Innovation Studio, Group 05

Turns saved short-form videos into AI-analyzed, brand-specific content briefs.

## Run it

```bash
git clone https://github.com/lexicookz/LyreBird.git
cd LyreBird
nvm use          # Node 22 (installs nvm/node if missing — see below)
npm install
cp .env.example .env
```

Fill in `.env` (see below), then:

```bash
npx expo start --clear
```

Scan the QR code with your phone's camera (iOS) or the Expo Go app (Android).

**Requirements:**
- Node 22 LTS — if you don't have `nvm`: `curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash`, then `nvm install 22`
- [Expo Go](https://expo.dev/go) app on your phone, updated (this runs on **SDK 57**)
- Phone and laptop on the same WiFi — if it won't connect, try `npx expo start --tunnel`
- If Expo Go prompts you to sign in, run `npx expo login` in the terminal first

### Environment variables

The app won't start without a `.env` file. Copy `.env.example` and fill in:

| Variable | Where to get it |
|---|---|
| `EXPO_PUBLIC_SUPABASE_URL` | Supabase → Project Settings → API |
| `EXPO_PUBLIC_SUPABASE_ANON_KEY` | Supabase → Project Settings → API (the **anon** key) |
| `EXPO_PUBLIC_WORKER_URL` | `https://lyrebird-worker.onrender.com` |

> Never put the `service_role` key in the app's `.env`. It bypasses row-level security. It belongs only in `worker/.env`.

Restart Expo with `--clear` after changing `.env`. You need Supabase project access to get the anon key — ask a teammate.

### Using the app

- Sign up with an email and password. You must be signed in to see anything; there is no offline mode.
- Analysis runs on the hosted worker (auto-deploys from `main` to Render). Nobody needs to run a backend locally.
- The free Render plan sleeps after 15 minutes of inactivity, so the first request can take about 50 seconds. That is normal.
- Transcoding very large videos may fail on the free tier. Analysis itself is fine.

### Tests

```bash
npx tsc --noEmit   # type check
npm test           # Jest + React Native Testing Library
```

## What's built so far

- **Accounts** — real Supabase auth (sign up, log in, sign out from Settings)
- **Bottom tab navigation** — Library / Search / Briefs / Calendar
- **Library** — clip cards with thumbnails, status, tag filtering, sorting, paging and delete
- **Import** — add videos from the camera roll; analysis starts automatically, with retry on failure
- **Search** — full-text search through Postgres, including transcripts
- **Video Detail** — AI breakdown (hook, transcript, shot beats, pacing, CTA, funnel stage)
- **Briefs** — generated by Gemini and rewritten in a brand's voice; every version is kept
- **Brand Profile** — editable name, product, audience, tone
- **Calendar** — scheduled briefs with drag and drop, saved to the database
- **Settings** — Appearance (light/dark/follows phone) and Sign out

Clips, analyses, briefs and the calendar are stored in Supabase.

## Known gaps

- `whyItWorks`, `audioStyle` and `description` are returned by the analysis but not yet shown on Video Detail.
- Clip tags have no source yet; a predefined tag list is planned.

## Tech stack

Expo (React Native) + TypeScript · Supabase (Postgres, auth, RLS) · Python/FastAPI worker on Render · Gemini
